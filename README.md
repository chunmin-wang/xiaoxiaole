# 🍬 糖果消消乐 · Candy Match

一款使用**原生 HTML / CSS / JavaScript** 实现的经典三消（Match-3）网页游戏，单文件、零依赖，双击即可在浏览器中游玩。

## 🎮 玩法

- 点击选中一颗糖果，再点击相邻糖果进行交换
- 3 个及以上相同糖果连成一线即可消除
- 消除后上方糖果自动下落补充，连续消除触发 **连击加成**（Combo ×N）
- 在 **20 步** 内达到 **1200 分** 目标即可通关

## ✨ 功能特性

- 🍭 8×8 棋盘、6 种糖果
- 🔥 级联消除 + 连击倍率计分
- ⬇️ 重力下落 + 顶部补充动画
- 💡 提示系统（找不到可消除步自动重洗）
- 🔊 Web Audio 实时音效（需用户交互后生效）
- 🎉 通关撒花特效、三星评级
- 📱 响应式布局，手机/电脑均可玩

## 🛠️ 技术要点

- 纯 Canvas-free DOM 实现，基于 CSS transform 动画
- 匹配检测：水平 + 垂直扫描
- 无解检测：`hasAnyMove()` 预判 + 自动重洗
- 防御性设计：消除动画中点击安全忽略，下落后的格子点击坐标实时读取
